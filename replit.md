# Running this project

The event landing page is built with plain HTML, CSS, and JavaScript. It does not need Node packages, React, or a Convex connection to run.

The Replit preview serves the project root with Python's built-in static file server on port 5000. To run it locally, use:

```sh
python3 -m http.server 5000
```

The page entry point is `index.html`; styles and browser interactions are in `styles.css` and `script.js`.
